# ML-Projects

A collection of machine learning projects and experiments, built and prototyped in Google Colab.

## Contents

| Notebook | Description |
|---|---|
| [`Linear_Regression.ipynb`](./Linear_Regression.ipynb) | Implementation of a linear regression model — covers data preprocessing, model training, evaluation, and visualization of results. |

## Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or Google Colab
- Common ML/data libraries: `numpy`, `pandas`, `matplotlib`, `scikit-learn`

### Installation

Clone the repository:

```bash
git clone https://github.com/procoder369/ML-Projects.git
cd ML-Projects
```

Install dependencies:

```bash
pip install numpy pandas matplotlib scikit-learn
```

### Usage

Open any notebook locally with Jupyter:

```bash
jupyter notebook Linear_Regression.ipynb
```

Or open it directly in [Google Colab](https://colab.research.google.com/) by uploading the notebook or linking the GitHub URL.
