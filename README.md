## 📖 Overview

**ML-Projects** is a growing portfolio of hands-on machine learning implementations, each focused on a core algorithm — from data preprocessing and exploratory analysis to model tuning and evaluation. Every notebook is self-contained and reproducible in Google Colab.

## ✨ Features

- 🧹 End-to-end workflows: preprocessing → training → evaluation → visualization
- 🔍 Exploratory Data Analysis (EDA) with `seaborn`/`matplotlib`
- 🎯 Hyperparameter tuning via `GridSearchCV`
- 📊 Clear performance metrics for every model
- ☁️ Zero setup — runs directly in Google Colab

## 📚 Notebooks

| 📓 Notebook | 📝 Description | 🎯 Result |
|---|---|---|
| [`Linear_Regression.ipynb`](./Linear_Regression.ipynb) | Linear regression — preprocessing, training, evaluation & visualization | — |

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/procoder369/ML-Projects.git
cd ML-Projects

# Install dependencies
pip install numpy pandas matplotlib seaborn scikit-learn

# Launch Jupyter
jupyter notebook
```

Or open any notebook directly in **Google Colab** — no local setup required.
